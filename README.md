# Laptop_Cooling_Pad
It's a CAD project with 3D printable files. And is specifically designed for my 14inch YOGA laptop but other Laptops which have dual fan intakes from bottom might also be able to use this. This has ATmega16 Controlling two 20000 RPM fans which run at 12V and one 6000 RPM 5V fan to cool the hottest part on the laptop located in the top-mid region.
